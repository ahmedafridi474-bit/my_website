MONEYWISE — CREATIVE FOUR-PAGE WEBSITE

Pages:
- index.html: Home
- budget.html: Budgeting and Saving
- banking.html: Banking and Investment
- contact.html: About and Contact
- css/style.css: Shared styling

HOW TO RUN:
1. Extract this ZIP.
2. Open the MoneyWise_Creative folder in VS Code.
3. Open index.html in your browser.
4. Keep the css folder beside the HTML pages.

CUSTOMIZE:
- Replace Student One, Student Two and Student Three with your real group members' names.
- Images are loaded from Unsplash, so internet access is needed to display them.
- The contact form is a front-end example and does not send/store messages.

The website uses HTML and CSS only. CSS includes colors, font sizes, spacing, borders,
simple flex layouts, hover effects and a mobile media query. No JavaScript or Bootstrap.
